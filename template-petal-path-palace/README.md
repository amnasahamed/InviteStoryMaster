# Petal Path Palace

InviteStory template — layered parallax Sikh / North-Indian wedding invitation.

## Dev

```bash
npm install
npm run dev
```

Opens on http://localhost:3020

## Customize

Edit **only** `src/config.ts` per customer.

## Layers

| File | Role |
|---|---|
| `05-sky-palace.png` | Deep background |
| `04-garden-guests.png` | Midground garden + guests |
| `03-couple.png` | Couple cutout |
| `02-foreground-guests.png` | Near guests |
| `01-arch-frame.png` | Foreground floral arch |
| `source-full.png` | Soft cohesion glaze |

## Rules

- One event (Wedding) only
- No RSVP
- Footer → `@invitestory.in`
- Calendar & maps from config
